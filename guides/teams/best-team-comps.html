📐 配队基础原则

在绝区零中，一支完整的队伍由3名角色组成。合理的配队需要满足以下核心原则：

  • 属性共鸣：队伍中有2名相同属性的角色时，激活属性共鸣提供强力被动（如火队双火+15%攻击力，冰队双冰+10%对冻结暴击率）。优先凑齐2同属性。
  • 职能分工：理想配队 = 主C（强攻/异常）+ 击破手 + 辅助/副C。主C负责输出，击破手负责破韧，辅助负责增伤/减抗/护盾。
  • 输出窗口：击破敌人韧性条后会触发连携技，是主要爆发窗口。配队需确保在连携期间有足够伤害。
  • 灵活性：根据敌人属性（弱冰/弱火/弱以太/弱物理）灵活调整配队，属性克制收益极大。

属性共鸣一览

双冰对冻结目标暴击率+10%
双火全队攻击力+15%
双以太异常积蓄效率+20%
双物理对失衡目标伤害+12%
双电全队能量回复+15%

🏆 T0 级配队

🥇 双冰永冻队

星见雅 + 莱卡恩 + 苍角

版本最强配队。双冰共鸣提供暴击率加成，莱卡恩群体减冰抗+高效击破，苍角提供攻击Buff与冻结延长。雅的终结技在冻结窗口内打出成吨核爆伤害。三人连锁完美：莱卡恩击破→苍角连携增伤→雅终结技爆发。

替代方案：雅→艾莲（伤害略低但更稳定），莱卡恩→安比（A级击破），苍角不可替代。

🥇 以太特化队

朱鸢 + 青衣 + 妮可

对单爆发天花板。双以太共鸣加速异常积蓄，青衣极速击破创造窗口，妮可提供减防聚怪。朱鸢在击破期间倾泻弹药打出炸裂单体爆发。Boss战/T0表现无可匹敌。

替代方案：青衣→安比（损失击破效率但可玩），妮可→丽娜（提升穿透）。

🔥 T1 级配队

火队

11号 + 珂蕾妲 + 本

双火共鸣提供全队+15%攻击力。珂蕾妲火伤减抗+击破，本提供护盾和额外火伤。11号火力压制下的清杂效率极高。火队AOE拉满，日常刷本效率T0。

双冰速切队

艾莲 + 青衣 + 苍角

艾莲与青衣的速切相性极好。青衣快速击破后，艾莲打满残影+终幕剪裁。苍角Buff加持下爆发可观。相比莱卡恩版本，击破速度更快但少了减冰抗。

物理特化队

猫又 + 派派 + 可琳

双物理共鸣对失衡增伤。猫又的闪避反击+派派的物理异常积蓄+可琳的高倍率终结技，形成物理连携循环。适合对付弱物理的Boss。

💰 平民配队方案

对于零氪或微氪玩家，以下是全A级或单S级的性价比配队推荐：

队伍主C击破辅助共鸣
冰系平民队 艾莲(常驻可歪)/苍角(主C位) 安比 苍角/妮可 双冰
火系平民队 11号(常驻可歪) 安比 本/妮可 双火(带本)
以太过渡队 妮可(输出位) 安比 任意辅助 灵活
物理平民队 猫又(常驻可歪)/派派 安比 可琳/妮可 双物理

💡 安比是A级角色中唯一的击破手，泛用性极高，几乎所有平民配队都带她。资源优先给她。

🔁 深渊（式舆防卫战）二队规划

式舆防卫战（深渊）需要两支队伍。以下是推荐的资源分配策略：

  1. 一队：用最强的限定S主C（雅/朱鸢）+ 她的最佳搭档 + 辅助。这是你的主力输出队。
  2. 二队：用常驻S主C（11号/猫又/艾莲）+ 安比（通用击破）+ 通用辅助。
  3. 辅助/击破共享：苍角和安比可以跨队使用。优先培养这两个泛用角色，她们的养成收益覆盖两支队伍。
  4. 资源分配：主C拉到60级+核心技满级，辅助/击破至少50级+核心技9级。不要分散投资多个主C。

推荐深渊二队分配方案

一队（主力）星见雅 + 莱卡恩 + 苍角
二队（副队）朱鸢 + 安比 + 妮可
一队备选艾莲 + 苍角 + 安比
二队备选11号 + 珂蕾妲 + 本

❓ 常见问题 FAQ

Q1: 配队必须凑齐属性共鸣吗？

优先凑共鸣，但不必牺牲功能。比如莱卡恩+苍角配任何冰C都比硬凑共鸣好。

Q2: 没有S级击破手怎么办？

安比完全够用。她是最泛用的击破手，练好安比=所有队伍都有击破位。

Q3: 一队和二队资源如何分配？

优先把一队主C拉满(60级)，二队主C到50级即可。辅助/击破50级即可。
